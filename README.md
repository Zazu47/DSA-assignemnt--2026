Overview
This repository contains two distributed systems:
1. Library and Resource Management System: a Ballerina RESTful API + CLI client for tracking books, devices, and spaces across campuses.
2. Rental Accommodation System: a gRPC-based platform (Ballerina) for property listings and bookings.
